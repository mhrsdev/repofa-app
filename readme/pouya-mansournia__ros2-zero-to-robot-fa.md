## About

A complete, project-based ROS 2 course written in Persian (Farsi), covering everything from the first ROS 2 node to a fully deployed autonomous mobile robot (AMR): architecture, workspaces, TF2, URDF/Xacro, RViz, Gazebo simulation, `ros2_control`, sensor fusion, SLAM, Nav2, Behavior Trees, MoveIt 2, multi-robot fleets, Docker/CI-CD, industrial hardware (Jetson/Raspberry Pi/ESP32, CAN bus, EtherCAT), sim-to-real deployment, and safety-critical QoS/DDS design.

A dedicated practical appendix walks through the complete **SolidWorks → URDF** pipeline for real robot assemblies, supported by real exporter screenshots and diagrams. A second appendix covers ROS 2 distributions, release lifecycle, LTS vs. non-LTS, Rolling Ridley, and a practical framework for choosing (and migrating between) ROS 2 distributions.

- 20 chapters + 2 practical appendices
- Continuous running project: **ARCHO**, a warehouse AMR
- Built around **ROS 2 Jazzy**
- Companion repository with a fully modeled robot: [warehouse-amr-ros2](https://github.com/Pouya-Mansournia/warehouse-amr-ros2)
- Light/dark reading mode
- Built-in navigation
- No build step — pure static HTML

## درباره کتاب

این کتاب مسیر یادگیری ROS 2 را از صفر تا ساخت و استقرار یک ربات متحرک خودران واقعی طی می‌کند.

در تمام فصل‌ها، یک پروژه پیوسته به نام **ARCHO** همراه خواننده است؛ یک ربات متحرک انبار که مرحله‌به‌مرحله از یک مدل ساده به یک سیستم کامل دارای شبیه‌سازی، کنترل، مکان‌یابی، مسیریابی، سخت‌افزار واقعی و معماری صنعتی تبدیل می‌شود.

کتاب در ۶ بخش اصلی و دو پیوست عملی سازمان‌دهی شده است:

| بخش | موضوع |
| --- | --- |
| ۱ | پایه‌های ROS 2 — معماری، محیط توسعه و ارتباطات |
| ۲ | ساختن بدنه ARCHO — URDF/Xacro، TF2 و RViz |
| ۳ | شبیه‌سازی و کنترل — Gazebo، `ros2_control` و Odometry |
| ۴ | درک محیط و خودمختاری — SLAM، Nav2، Behavior Tree و MoveIt 2 |
| ۵ | مقیاس‌پذیری و تحویل نرم‌افزار — Multi-Robot و Docker/CI-CD |
| ۶ | سخت‌افزار و استقرار صنعتی — Jetson/RPi/ESP32، CAN/EtherCAT، Sim-to-Real و QoS/DDS |
