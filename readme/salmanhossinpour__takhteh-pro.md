## 🌟 چرا این برنامه نجات‌بخش ساعات کاری شماست؟

آیا جلسات زوم بی‌ارزش طولانی شده‌اند؟ آیا پروژه‌ها روی اعصابتان رفته و نیاز به یک پارتنر کل‌کل در زمان چای/قهوه دارید؟  
این تخته‌نرد دقیقا برای **محیط‌های کاری، زمان استراحت و خلوت‌های اداری** طراحی شده است!

---

## 🚀 امکانات و ویژگی‌های شاخص (Features)

### 1. 🛡️ دکمه جادویی «رئیس آمد!» (Boss Key / Anti-Busted Mode)
با فشردن فوری یک کلید یا کلیک روی دکمه رئیس، صفحه بازی غیب شده و به یک **داشبورد مدیریتی، جدول اکسل با فرمول‌های پیچیده یا کدهای VSCode** تبدیل می‌شود تا صندلی‌تان به خطر نیفتد! 🤫

### 2. 🎯 انیمیشن‌های روان و فیزیکی حرکت مهره‌ها (Smooth Motion)
مهره‌ها با انیمیشن‌های واقعی نرم (Framer Motion Engine) از روی خانه خود سر خورده و روی خانه مقصد فرود می‌آیند. حسی دقیقاً مشابه تخته نرد واقعی روی چوب گردوی معطر!

### 3. 🇮🇷 چیدمان و قوانین ۱۰۰٪ اصیل ایرانی (Traditional Board Layout)
- جهت حرکت پادپادساعت‌گرد (Counter-Clockwise) برای سفید و ساعت‌گرد برای مشکی.
- خانه حریف و خانه خودی (Home Board) دقیقا مطابق سنت ایرانی (خانه ۱ تا ۶ سمت راست پایین برای سفید، ۱۹ تا ۲۴ سمت راست بالا برای مشکی).
- قابلیت **چرخش دستی جهت تخته** (برای کسانی که چپ‌دست هستند یا چیدمان متفاوتی ترجیح می‌دهند).

### 4. 🧭 فلش هوشمند راهنمای مسیر حرکت (Movement Route Guide)
هنوز مسیر حرکت مهره‌ها در تخته را اشتباه می‌روید؟ با روشن کردن دکمه «نمایش مسیر حرکت»، فلش نئونی مسیر دقیق حرکت هر دو رنگ را به شما نشان می‌دهد.

### 5. 🤖 ربات هوشمند با چند سطح دشواری (Smart AI Engine)
- **مبتدی (Easy):** جهت روحیه دادن به شما و رفع خستگی!
- **متوسط (Medium):** یک همکار معمولی که گهگاهی اشتباه می‌کند.
- **حرفه‌ای (Hard / Master):** محاسبات ریاضی تاس و بستن خانه‌ها مثل استادهای قدیمی قهوه‌خانه!

### 6. 🌐 آنلاین چندنفره و اتاق‌های خصوصی (Online Multiplayer)
ایجاد اتاق بازی و فرستادن لینک به همکارتان در طبقه بالا یا همکار ریموت آن‌طرف شهر، بدون نیاز به ثبت‌نام‌های طولانی.

### 7. 🗣️ کل‌کل و چت اداری (In-Game Chat & Emotes)
دارای استیکرهای اصیل تخته‌نردی («مارو مارس نکنی!»، «شانس آوردی!»، «تاس نریز داداش!») جهت افزایش صمیمیت و هیجان اداری!

### 8. 🎨 تم‌ها و پوسته سفارشی (Custom Themes)
- چوب گردوی کهنسال (Walnut Classic)
- سنگ مرمر سلطنتی (Royal Marble)
- تم مدرن تاریک (Cyber Dark)

### 9. 🔤 فونت فارسی استاندارد و زیبا (Vazirmatn Font)
تمام بخش‌های برنامه از فونت محبوب **وزیرمتن (Vazirmatn)** در تمام اوزان (لایت، نرمال، بولد و بلک) استفاده می‌کند.

## 🛠️ راهنمای نصب و اجرا در محیط محلی (Local Setup)

اگر می‌خواهید بازی را روی سیستم خود یا سرور داخلی شرکت اجرا کنید:

### پیش‌نیازها (Prerequisites)
- [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر)
- مدیریت بسته‌ها: `npm` یا `pnpm` یا `yarn`

### ۱. کلون کردن مخزن (Clone repository)
```bash
git clone https://github.com/your-username/work-break-backgammon.git
cd work-break-backgammon
```

### ۲. نصب بسته‌ها (Install dependencies)
```bash
npm install
```

### ۳. اجرای برنامه در حالت توسعه (Run Dev Server)
```bash
npm run dev
```
برنامه روی آدرس زیر آماده استفاده است:  
👉 **`http://localhost:3000`**

### ۴. ساخت نسخه نهایی (Production Build)
```bash
npm run build
npm run start
```

## ⌨️ کلیدهای میانبر (Shortcuts)

| کلید | عملکرد |
| :---: | :--- |
| `Space` / `Enter` | انداختن تاس |
| `Esc` / `B` | **دکمه فوری رئیس آمد! (Boss Key)** |
