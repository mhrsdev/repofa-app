# uiuxlabz — Premium Free HTML Website Templates

> A curated marketplace of **120+ premium, framework-free HTML templates** — each one designed from its subject, MIT licensed, fully responsive and ready to deploy on GitHub Pages.

## ✨ Why uiuxlabz?

- **Topic-driven originality** — every template is bespoke, never a recolored scaffold
- **Framework-free** — pure HTML5, CSS and vanilla JavaScript, zero dependencies
- **MIT licensed** — free for personal, commercial and client projects
- **GitHub Pages ready** — every repo ships with a deploy workflow
- **Mobile-first & SEO-friendly** — semantic markup, accessible, fast

## 🌐 Live Site

- **Marketplace:** https://uiuxlabz.github.io/uiuxlabz/

## 🗂️ How It's Organized

Each template lives in its own repository under the `uiuxlabz` GitHub organization, and is listed in this marketplace with a dedicated page covering its features, pages/sections, FAQ and links to the repo and live demo.

- `templates/<name>.html` — dedicated page for each template
- `categories/<category>.html` — browse templates by category
