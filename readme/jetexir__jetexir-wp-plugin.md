# Jetexir

## Download

Production-ready version from WordPress.org: https://wordpress.org/plugins/jetexir/

Jetexir integrates with WooCommerce to help you further enhance your website.

Free forever and open source (GPLv3). All 24 add-ons are included at no cost, with no premium tier and no hidden upsells.

## Addons

### Product (13)

* Fast Search: live product search dropdown for WordPress and WooCommerce search forms.
* Call for price: show a Call button on products that have no price set.
* Products Compare: let customers compare products side by side on a dedicated compare page.
* Product Extra Fields: add priced extra product fields saved as order item meta data.
* Products FAQ: add an accordion FAQ section to individual product pages.
* Product Price Variation: advanced settings for WooCommerce variable product pricing.
* Product Quantity: quantity stepper buttons with min, max, and step limits.
* Related Products: show related products by category, tag, attribute, or manual selection.
* Product Sale Badge: customize the text, style, and position of the product sale badge.
* Sale progress bar: display a progress bar showing how close a product is to its sale.
* Product Social Share: add social media share buttons to WooCommerce product pages.
* Variation Image Swatches: replace dropdowns with image and color variation swatches on product pages.
* Products WishList: let customers save products to a wishlist and share it.

### Cart (3)

* Fly Cart: slide-in floating cart that lets customers view and edit cart without leaving the page.
* Menu Cart: display a cart icon with item count and dropdown in your site menu.
* Toast Notices: show WooCommerce notices and add-to-cart feedback as dismissible toast popup notifications.

### Checkout (1)

* Checkout Fields: add, remove, and reorder WooCommerce checkout fields with custom validation rules.

### Order (3)

* First Order Coupon: offer a discount coupon to customers placing their very first order.
* Order Number: generate custom sequential or formatted order numbers for your store.
* Order Status: create custom order statuses and manage their WooCommerce email notifications.

### Customizations (3)

* Announcement Bar: show promotional announcement bars with multiple style and display options.
* Currency Symbol: change the WooCommerce currency symbol and its placement.
* Dashboard Styles: restyle the WooCommerce My Account dashboard with themes, colors, a banner, and a custom greeting.

### Utility (1)

* Woo Developer Feed: display the official WooCommerce developer blog feed in your dashboard.

The plugin also ships a global style customizer, SVG media support, and a debug mode.

## Development

Install requirements:

```shell
npm install
```

```shell
composer install
```

Compile scss files using SASS

```shell
npm run jetexir-css
```

Compile js files using WebPack

```shell
npm run jetexir-build-js
```
