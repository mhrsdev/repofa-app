# notebooklm-obsidian-chrome

Export **Gemini Notebook / NotebookLM** chats into **Obsidian** with a Chrome extension.

## Quick start

Full guide (install, proxy, daily use, troubleshooting):

👉 **[chrome-extension/README.md](chrome-extension/README.md)**

```bash
git clone https://github.com/AmirHossein-PapakiKashani/notebooklm-obsidian-chrome.git
cd notebooklm-obsidian-chrome
```

Then load the `chrome-extension/` folder as an **unpacked** extension in Chrome (`chrome://extensions` → Developer mode → Load unpacked).

## Requirements

- Chrome
- Obsidian + **Local REST API** plugin
- Optional Windows HTTP proxy script (included) when Chrome rejects the plugin HTTPS certificate
