# scripts

A collection of shell scripts and tools for Arch/Parch Linux, maintained by [Sohrab Behdani](https://github.com/behdanisohrab).

## Scripts

### [mkappimage](./mkappimage/)

Pack any installed Arch Linux program into a portable AppImage with its shared libraries. Handles library bundling, RPATH patching, `.desktop` and icon resolution automatically.
