# DevoPort - AI CLI Account Manager (GUI)

![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)
![PySide6](https://img.shields.io/badge/PySide6-6.5.0+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

**DevoPort** is a graphical user interface (GUI) application for managing CLI accounts of AI tools like ZCode, Claude, and more. It allows users to easily switch between accounts, back up configurations, and restore them.


## 🌟 Features

✅ **Account Management** – Add, edit, and delete AI CLI accounts.
✅ **Backup & Restore** – Save and restore account configurations.
✅ **Multi-Language Support** – English and Persian (فارسی).
✅ **Dark/Light Theme** – Customize the app's appearance.
✅ **Search Functionality** – Quickly find accounts and settings.
✅ **Standalone Executable** – No need to install Python or dependencies.

---

## 📥 Installation & Usage

### **For End Users (Windows)**
1. **Download** the latest `DevoPort-Setup.exe` from the [Releases](https://github.com/yourusername/DevoPort/releases) page.
2. **Run** the installer and follow the instructions.
3. **Launch** DevoPort from the Start Menu or Desktop shortcut.

### **How to Use**
1. **Add an Account** – Click the "+" button and enter your AI CLI credentials.
2. **Switch Accounts** – Select an account from the list.
3. **Backup Configurations** – Go to the "Backups" tab and create a backup.
4. **Restore Configurations** – Select a backup file and restore it.



# DevoPort - مدیر حساب‌های CLI ابزارهای هوش مصنوعی (رابط کاربری گرافیکی)

![Python](https://img.shields.io/badge/Python-3.10+-blue.svg)
![PySide6](https://img.shields.io/badge/PySide6-6.5.0+-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

**DevoPort** یک اپلیکیشن رابط کاربری گرافیکی (GUI) برای مدیریت حساب‌های CLI ابزارهای هوش مصنوعی مانند ZCode، Claude و غیره است. این برنامه به کاربران امکان می‌دهد به راحتی بین حساب‌ها جابجا شوند، تنظیمات را پشتیبان‌گیری کنند و بازیابی کنند.



## 🌟 ویژگی‌ها

✅ **مدیریت حساب‌ها** – افزودن، ویرایش و حذف حساب‌های CLI هوش مصنوعی.
✅ **پشتیبان‌گیری و بازیابی** – ذخیره و بازیابی تنظیمات حساب‌ها.
✅ **پشتیبانی از چند زبان** – انگلیسی و فارسی.
✅ **تم تاریک/روشن** – سفارشی‌سازی ظاهر برنامه.
✅ **جستجوی سریع** – یافتن سریع حساب‌ها و تنظیمات.
✅ **فایل اجرایی مستقل** – نیازی به نصب پایتون یا وابستگی‌ها نیست.

---

## 📥 نصب و استفاده

### **برای کاربران نهایی (ویندوز)**
1. **دانلود** آخرین نسخه `DevoPort-Setup.exe` از صفحه [انتشارها](https://github.com/yourusername/DevoPort/releases).
2. **اجرای** فایل نصبی و دنبال کردن دستورالعمل‌ها.
3. **اجرای** DevoPort از منوی Start یا میانبر دسکتاپ.

### **نحوه استفاده**
1. **افزودن حساب** – روی دکمه "+" کلیک کرده و اطلاعات حساب CLI هوش مصنوعی خود را وارد کنید.
2. **جابجایی بین حساب‌ها** – حسابی را از لیست انتخاب کنید.
3. **پشتیبان‌گیری از تنظیمات** – به تب "پشتیبان‌گیری" رفته و یک پشتیبان ایجاد کنید.
4. **بازیابی تنظیمات** – یک فایل پشتیبان را انتخاب کرده و بازیابی کنید.
