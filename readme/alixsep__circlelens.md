# CircleLens

CircleLens turns the people around you into a practical relationship map. Add people, estimate what they bring, understand how they connect, and choose a useful next step.

![CircleLens screenshot](images/sample-screenshot-v.0.1.0.png)

## The workflow

1. **Map** your circle by adding people and connecting them.
2. **Estimate** three current outcomes from 0–5: wealth/access (W), social or romantic reach (R), and status/influence (S).
3. **Analyze** the network through six explainable lenses: goal fit, warm paths, bridge resilience, reciprocity, dormant ties, and network coverage.
4. **Act** on the result as a conversation prompt—not as proof of intent, consent, or obligation.

Your graph stays in the browser. Export a JSON backup when you want to keep a copy.

## Run locally

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).
