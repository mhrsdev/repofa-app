# Pelakyab

This is a practice project built with Flask that determines which city in Iran a vehicle's license plate belongs to.

This project is a "license plate finder" specifically designed for Iranian vehicle license plates.

<img width="960" height="215" alt="image" src="https://github.com/user-attachments/assets/8031b6f4-9bc0-49e3-aa8e-1a37299188c2" />

As you can see in the picture above, this is a standard Iranian license plate commonly found on vehicles in Iran.

## How does my project work?
On the main page, you can see a form where you need to enter the last two digits of the license plate. After entering the digits, you will be redirected to the next page, where you can see which city the license plate belongs to in Iran.
