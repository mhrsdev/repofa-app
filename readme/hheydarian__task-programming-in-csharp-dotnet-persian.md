## 💡 چرا این پروژه؟

کتاب **Task Programming in C# and .NET** نوشته‌ی *واسکاران سارکار (Vaskaran Sarcar)*، راهنمایی دقیق و عملی برای درک ماهیت `Task`، الگوهای کتابخانه موازی‌سازی وظایف (TPL)، Continuationها، مدیریت خطاها و لغو ایمن عملیات ناهمگام است.

هدف ما در این پروژه اوپن‌سورس:
* 🎯 **ترجمه‌ای روان، فنی و دقیق** برای تسلط عمیق بر `async` / `await` و چرخه حیات تسک‌ها
* 💻 **ارائه رایگان تمام فصل‌ها و مثال‌های #C** برای یادگیری عملی سناریوهای واقعی همزمانی
* 🌍 **غنی‌سازی منابع تخصصی فارسی** برای توسعه‌دهندگان اکوسیستم دات‌نت
