---

## ✨ قابلیت‌های کلیدی

### 🔄 Dynamic DNS (DDNS)
- ثبت و مدیریت خودکار رکورد‌های **A، AAAA و CNAME**
- سازگاری با مودم‌های **D-Link، TP-Link و Mikrotik**
- پشتیبانی از **Raspberry Pi** و دستگاه‌های مبتنی بر لینوکس
- امکان ایجاد **اسکریپت شخصی** برای بروزرسانی رکورد
- رابط کاربری ساده، سریع و حرفه‌ای

### 🔁 Reverse Proxy
- انتشار سرویس‌های داخلی روی اینترنت **بدون نیاز به آی‌پی ثابت**
- پشتیبانی از **پروتکل TCP ، UDP و همجنین HTTP**
- امکان **رزرو پورت یا آدرس دلخواه**

### 🛠 ابزارهای کمکی
- ابزار بررسی وضعیت آی‌پی و رکوردها
- گزارش‌گیری و لاگ بروزرسانی‌ها
- مستندات فارسی و پشتیبانی جامعه
