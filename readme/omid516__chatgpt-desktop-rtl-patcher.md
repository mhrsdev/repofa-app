# ChatGPT Desktop RTL Patcher

ابزاری محلی و آفلاین برای بهبود نمایش فارسی، عربی و عبری در نسخه macOS برنامه
ChatGPT Desktop. پچر فونت Vazirmatn را داخل `app.asar` قرار می‌دهد و CSS محتاطانه‌ای
اضافه می‌کند؛ بخش‌های کد، ترمینال، diff و ویرایشگرها عمداً LTR و monospace باقی
می‌مانند.

این پروژه رسمی نیست و هیچ وابستگی یا ارتباطی با OpenAI ندارد.

## هشدارهای امنیتی

- این ابزار فایل‌های نصب محلی ChatGPT را تغییر می‌دهد.
- تغییر `app.asar` امضای رسمی برنامه را نامعتبر می‌کند. ابزار پس از تغییر، برنامه را
  با امضای ad-hoc محلی امضا و سپس امضا را اعتبارسنجی می‌کند.
- قبل از هر patch یک بکاپ نسخه‌دار و checksum‌دار می‌سازد.
- به‌روزرسانی ChatGPT ممکن است patch را حذف کند؛ پس از هر آپدیت ابتدا `dry-run` بگیرید.
- ابزار `sudo` اجرا نمی‌کند، رمز عبور نمی‌گیرد، شبکه را صدا نمی‌زند و cookies، session
  یا token را نمی‌خواند.
- اجرای برنامه‌های تغییریافته همیشه ریسک دارد. کد را پیش از اجرا مرور کنید.

## نیازمندی‌ها

- macOS
- Node.js 18 یا جدیدتر و npm
- ChatGPT Desktop در `/Applications/ChatGPT.app` یا
  `~/Applications/ChatGPT.app`، یا یک مسیر سفارشی
- بسته‌بودن کامل ChatGPT
- دسترسی نوشتن به برنامه و فضای آزاد کافی
- ابزار استاندارد macOS به نام `codesign`

## نصب

```bash
cd chatgpt-desktop-rtl-patcher
npm install
npm run check
```

فونت از پکیج npm `@fontsource/vazirmatn` در زمان نصب پروژه دریافت می‌شود. عملیات
patch هیچ فایل یا کدی از اینترنت دریافت نمی‌کند.

## بررسی و dry-run

این فرمان فقط می‌خواند و هیچ فایلی را تغییر نمی‌دهد:

```bash
npm run dry-run
```

مسیر سفارشی:

```bash
node index.js --dry-run --app "/custom/path/ChatGPT.app"
```

گزارش شامل نسخه، اندازه ASAR، تعداد فایل‌های JS/CSS، وجود patch، کاندیداهای تزریق،
فضای لازم، وضعیت اجرای برنامه و امکان patch است. `--check` همان بازرسی read-only
را با خروجی مناسب اسکریپت‌ها انجام می‌دهد.

## Patch

ابتدا ChatGPT را کاملاً Quit کنید:

```bash
npm run patch
```

اجرای تعاملی تأیید می‌خواهد. برای اجرای غیرتعاملی آگاهانه:

```bash
node index.js --patch --yes
```

برای مسیر سفارشی:

```bash
node index.js --patch --app "/custom/path/ChatGPT.app"
```

ابزار ASAR را در پوشه موقت استخراج می‌کند، بهترین bundle مربوط به renderer را با
شواهد محتوایی انتخاب می‌کند، چهار وزن 400/500/600/700 فونت را اضافه می‌کند، ASAR
جدید را می‌سازد و دوباره استخراج و اعتبارسنجی می‌کند. تنها پس از موفقیت این مراحل
جایگزینی انجام می‌شود. marker به نام `CHATGPT_DESKTOP_RTL_PATCH_V1` از تزریق
تکراری جلوگیری می‌کند. fallback جاوااسکریپت فقط وقتی استفاده می‌شود که هیچ CSS
مناسبی وجود نداشته باشد.

اگر دسترسی نوشتن ندارید، ابزار متوقف می‌شود و `sudo` را خودکار اجرا نمی‌کند.
بهتر است مالکیت و محل نصب برنامه را آگاهانه اصلاح کنید یا یک نسخه متعلق به حساب
خود در `~/Applications` قرار دهید؛ از اجرای کورکورانه کل ابزار با sudo خودداری کنید.

## بکاپ و Restore

بکاپ‌ها حذف یا overwrite نمی‌شوند و در این مسیر هستند:

```text
~/Library/Application Support/chatgpt-desktop-rtl-patcher/backups/<timestamp>/
```

هر بکاپ شامل `app.asar`، `Info.plist` و `manifest.json` با SHA256 فایل‌های اصلی است.
بازگردانی آخرین بکاپ معتبر:

```bash
npm run restore
```

انتخاب بکاپ مشخص:

```bash
node index.js --restore --backup "/absolute/path/to/backup"
```

Restore نیز نیازمند بسته‌بودن ChatGPT و دسترسی نوشتن است، checksum را پیش و پس از
کپی بررسی می‌کند، برنامه را ad-hoc sign و امضا را verify می‌کند. بکاپ باقی می‌ماند.

## رفع خطا

- **ChatGPT is running:** از منوی برنامه Quit کنید و در Activity Monitor مطمئن شوید
  پردازش ChatGPT باقی نمانده است.
- **not writable:** برنامه معمولاً متعلق به administrator است. مجوز یا محل نصب را
  خودتان اصلاح کنید؛ ابزار هرگز sudo یا shell خام اجرا نمی‌کند.
- **insufficient disk space:** به دلیل استخراج، repack و verify چند برابر اندازه ASAR
  فضای موقت لازم است.
- **no credible renderer target:** نسخه برنامه تغییر ساختاری داشته است. patch نکنید؛
  خروجی dry-run و bundleها باید برای نسخه جدید بررسی شوند.
- **codesign failure:** patch به‌صورت خودکار از بکاپ همان تراکنش rollback می‌شود.
  خروجی `codesign --verify --deep --strict "/Applications/ChatGPT.app"` را بررسی کنید.
- **برنامه پس از patch اجرا نمی‌شود:** با `npm run restore` آخرین بکاپ را برگردانید.

از `xattr` استفاده نمی‌شود، چون تغییر ASAR به‌تنهایی دلیلی برای پاک‌کردن extended
attributes نیست.

## تأثیر آپدیت ChatGPT

Updater می‌تواند `app.asar` و `Info.plist` را جایگزین کند و patch را از بین ببرد.
پس از آپدیت، نسخه قدیمی را به نسخه جدید restore نکنید؛ ابتدا dry-run بگیرید و برای
نسخه جدید یک backup تازه بسازید.

## حذف کامل پروژه

ابتدا در صورت نیاز `npm run restore` را اجرا کنید. سپس پوشه پروژه را حذف کنید.
بکاپ‌ها مستقل‌اند؛ اگر دیگر لازم نیستند، فقط پس از بررسی مسیر و با اقدام دستی خودتان
پوشه مشخص بکاپ را حذف کنید. ابزار عمداً بکاپ‌ها را پاک نمی‌کند.

## محدودیت‌ها

- ساختار داخلی ChatGPT خصوصی و قابل‌تغییر است؛ انتخاب bundle بر اساس scoring محتاطانه
  انجام می‌شود، اما سازگاری با همه نسخه‌های آینده تضمین‌شده نیست.
- selectorها عمومی و دفاعی‌اند، با این حال امکان دارد یک کامپوننت جدید نیاز به
  selector محافظتی دیگری داشته باشد.
- fallback جاوااسکریپت URL فونت را نسبت به document اصلی resolve می‌کند و فقط برای
  بسته‌هایی مناسب است که assets را از ریشه renderer سرو می‌کنند.
- امضای ad-hoc هویت رسمی ناشر را بازنمی‌گرداند.
- Restore یک backup را فقط به همان مسیر برنامه‌ای برمی‌گرداند که manifest ثبت کرده است.

## توسعه و مشارکت

```bash
npm test
npm run check
```

smoke test فقط روی ASAR مصنوعی در پوشه موقت اجرا می‌شود و `/Applications` را تغییر
نمی‌دهد. تغییرات باید idempotency، rollback، حفاظت LTR و عدم دسترسی شبکه را حفظ کنند.
